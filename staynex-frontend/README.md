# Web App

Next.js application for the guest, owner, and admin experience.

Planned structure:

- `src/app/(marketing)` - Landing and informational pages.
- `src/app/(public)` - Search, property, room, checkout, and confirmation flows.
- `src/app/(owner)` - Owner dashboard surfaces.
- `src/app/(admin)` - Admin control surfaces.
- `src/components` - Shared web components.
- `src/features` - Feature-scoped UI and client logic.
- `src/lib` - Web-only utilities.
